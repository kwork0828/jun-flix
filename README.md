# jun-flix

> **상태: 완료 (1일 실습용 소규모 프로젝트)**
> 빌드 과정 없는 정적 웹페이지입니다.

넷플릭스 스타일로 **현재 상영 중인 영화** 포스터와 제목을 보여주는 웹페이지입니다.
[TMDb API](https://developer.themoviedb.org/)의 `movie/now_playing`을 한국어(`ko-KR`)로 호출합니다.

## 기능

- 페이지를 열면 현재 상영작 목록을 불러와 카드 형태로 표시
- API 호출 실패 시 안내 문구 표시

## 실행 방법

`index.html`을 브라우저로 열거나, 폴더에서 간단한 서버를 띄웁니다.

```bash
python -m http.server 8000   # http://localhost:8000
```

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 헤더와 영화 목록 영역 |
| `style.css` | 넷플릭스 스타일 다크 테마 |
| `app.js` | TMDb API 호출, 카드 렌더링 |
| `code` | 빈 파일 (삭제해도 됨) |

## 주의: API 키 노출

`app.js`에 TMDb API 키가 그대로 적혀 있고, 이 저장소는 공개(public) 상태입니다.
TMDb 설정 화면에서 **키를 재발급(폐기)** 하는 것을 권장합니다.
정적 페이지 구조에서는 키를 완전히 숨길 수 없으므로, 계속 공개할 경우 서버리스 함수로 호출을 감싸는 방식이 필요합니다.
